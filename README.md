# Firma de Gmail de Ana Cristina Velásquez

Instalador HTML de la firma y su imagen pública.

El nombre, los cargos y los datos de contacto son texto HTML seleccionable. El teléfono y el correo incluyen enlaces y solamente el sello se carga como imagen pública. El lienzo conserva las dimensiones originales de presentación: 520 × 260 px.

## Instalación

1. Abre la página publicada del repositorio.
2. Pulsa **Copiar firma**.
3. Pega el contenido en Configuración → Firma de Gmail.
