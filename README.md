# Firma de Gmail de Ana Cristina Velásquez

Instalador HTML de la firma y su imagen pública.

La firma se muestra a 520 × 260 px para mantener la proporción original sin ocupar demasiado espacio en Gmail.

## Instalación

1. Abre la página publicada del repositorio.
2. Pulsa **Copiar firma**.
3. Pega el contenido en Configuración → Firma de Gmail.
