# Firma de Gmail de Ana Cristina Velásquez

Instalador HTML de la firma y su imagen pública.

La firma utiliza el diseño original completo como imagen para conservar exactamente sus fuentes, iconos y posiciones. El HTML fija el lienzo en 520 × 260 px para que Gmail no lo muestre a tamaño natural.

## Instalación

1. Abre la página publicada del repositorio.
2. Pulsa **Copiar firma**.
3. Pega el contenido en Configuración → Firma de Gmail.
